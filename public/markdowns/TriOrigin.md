
> 一个用于展示个人项目与创作历程的静态网站。

---

## 🪄 项目背景

在持续进行创作与开发的过程中，我希望拥有一个轻量、独立的空间来记录自己的作品完成情况。
这个作品集网站不仅是一个展示平台，也是一个可以随时更新、反映我成长轨迹的“数字档案室”。
同时，它让访问者能快速了解我正在做什么、擅长什么。

---

## 🧩 项目简介

本项目旨在构建一个静态化、可扩展的个人作品集网站，用于展示我已有的项目成果，并通过直观的链接跳转访问项目演示或源代码。
项目数据完全由前端管理，无需依赖数据库，保持部署与维护的极简化。

---

## ⚙️ 核心功能

 - 🖼️ 展示个人项目及描述

 - 🔗 支持已部署项目的外部跳转

 - 🧾 Markdown 格式的个人简介与内容管理

 - 🧰 数据集中存储于前端 JSON 文件，便于更新与扩展

---

## 🧠 项目特性

 - ⚡ 纯前端静态部署，加载快速

 - 🧩 JSON 数据驱动内容更新，无需后端支持

 - 🧾 Markdown 内容渲染，兼顾可读性与编辑灵活性

 - 🎨 使用 Tailwind CSS 为 Markdown 内容提供一致、优雅的样式

 - 💡 极简结构，方便持续维护与个性化拓展

---

## 🛠 技术栈

- **前端**：Next.js、Tailwind CSS、MarkdownReader(marked)
- **部署**：AWS-EC2 Nginx
